# 应用图标

最终采用 **共线双圆 · 网格优化 · 浅色圆角底板版**。

## 资源结构

| 文件                                   | 用途                                                 |
| -------------------------------------- | ---------------------------------------------------- |
| `icon.svg` / `icon.png` / `icon.ico`   | 正式应用图标：浅色圆角底板、黑色线条，适用于深浅背景 |
| `variants/black.svg` / `.png` / `.ico` | 黑色线条、透明背景，适用于浅色背景                   |
| `variants/white.svg` / `.png` / `.ico` | 白色线条、透明背景，适用于深色背景                   |
| `design/geometry.svg`                  | 最终几何设计图，包含网格、坐标、中轴和辅助线         |
| `design/geometry.json`                 | 精确坐标、长度、角度和小尺寸调整参数                 |

SVG 是可编辑源文件，PNG 为 512 × 512 px；ICO 包含 16、24、32、48、64、128、256 px 图层。
仓库仅保留最终图标、配色变体和最终设计资料。历史试验版、重复资源及预览图归档在仓库外，生成的应用包放在被 Git 忽略的 `dist/` 中。

## 几何规范

- 设计画布为 512 × 512 px，主网格 16 px、辅助网格 8 px。主要折点和圆心对齐 8 px 网格；最终版不是 16 px 严格对齐试验版。
- 主体线宽 32 px，两条底边均为 80 px。斜线采用水平 1、垂直 2 的比例，倾角约 63.435°，顶角约 53.130°。
- 圆环中心线半径为 28 px，线宽 24 px，对应外径 80 px、内径 32 px。外圆圆心 O 为 `(296,136)`，内圆圆心 I 为 `(216,296)`。
- 外侧长斜线与主体右斜线平行，内圆连接线与主体左斜线平行；两个圆心与内圆连接线共线。
- 图形整体上移 8 px，底板不动。图形包围框为 `(72,96)` 至 `(440,408)`，中心为 `(256,252)`；画布中轴为 `x=256 / y=256`，主体两条主斜线的对称轴为 `x=216`。
- 底板位于 `(16,16)`，尺寸为 480 × 480 px，圆角半径 96 px，边框宽 4 px；填充色为 `#f5f5f4`，边框色为 `#dedbd7`。

设计图突出圆心 O、I；A、G 是由圆心、半径和斜率计算的连接点，精确值保留在 JSON 中，允许小数以保持几何关系。

## 导出与应用

16、24 px ICO 图层将圆环中心线半径增至 32 个源坐标单位，保持圆心、线宽和轴线不变，并同步调整圆周连接点，避免缩小后圆孔闭合。其他尺寸使用标准几何；每个 ICO 图层按目标尺寸直接渲染，不从单张 PNG 连续缩放。

`src/main/index.ts` 使用 `icon.ico` 作为 Windows 窗口图标，其他平台使用 `icon.png`；`electron-builder.yml` 使用 `icon.ico` 作为 Windows 打包图标。

修改造型时，应同步更新默认图标、两个配色变体及设计资料，并检查小尺寸 ICO 图层。切换配色时，将对应的 SVG、PNG、ICO 一并复制为 `icon.svg`、`icon.png`、`icon.ico`。
